# GOAL! 入試トレ シリーズ — 公式サイト（GitHub Pages）

ストア公開に必要な「プライバシーポリシー」「サポート」ページを置く静的サイト。

- 公開先: https://iwaokai.github.io/goaltore/
- プライバシーポリシー: https://iwaokai.github.io/goaltore/privacy.html
- サポート: https://iwaokai.github.io/goaltore/support.html

## 公開手順（初回）

```bash
bash ~/Developer/goaltore-site/publish.sh
```

## 更新手順

ファイルを編集して `git add -A && git commit -m "更新" && git push`。数分で反映。
